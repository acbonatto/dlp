# Dispositivos Lógicos Programáveis

Circuito decodificador de entrada BCD para display de 7 segmentos.
Plataforma alvo: Altera DE10-Lite
	
**proj03_bcdCounter7seg_de10Lite**
Circuito contador BCD com saída para display de 7 segmentos.

**proj05_contadorIncrDecr8bit_de10Lite**
Circuito contador binário de 8-bits com incremento/decremento e saída BCD com decodificador para display de 7 segmentos.
Plataforma alvo: Altera DE10-Lite
